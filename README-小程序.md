# 用药打卡微信小程序

这是网页版本对应的独立微信小程序。它不会加载网页，也不需要服务器。

## 功能

- 按日期和时段查看用药安排
- 记录或取消当天的用药完成时间
- 编辑药品名称、用法/规格、使用日期和时段
- 所有修改和打卡记录仅保存在当前微信设备

## 在微信开发者工具中打开

1. 选择“导入项目”。
2. 选择本文件所在目录（包含 `project.config.json` 的目录）。
3. 测试阶段可使用测试号；正式上传时将 `project.config.json` 中的 `appid` 替换为已注册小程序的 AppID。

正式发布需要小程序管理员登录微信开发者工具后上传代码，并在微信公众平台提交审核。
